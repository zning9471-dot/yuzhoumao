# Mochi · 入职指引页面

这是按「用户附件 (2).png」首页设计还原的新人入职引导页：麻球猫猫欢迎页 + 原有入职看板 + 知识库亮点模块 + 后台编辑中心。

## 功能清单

- 首页：麻球猫猫形象（图一）、欢迎语、5 个能力入口、标语横幅，版式与设计稿一致。
- 看板：身份卡、本周安排、入职旅程、我的新基地、附近美食、Mochi 问答。
- 知识库亮点模块：新人高频焦虑 · 一次解答（4 个问题，可后台增删改）。
- 后台编辑：`#admin` 进入，覆盖 15 个内容模块、191+ 个可编辑字段，支持增删列表项、导出/导入 JSON、恢复默认。
- 配色：整体采用「维妥科技 LOGO」渐变色调（紫 #967DFF → 蓝 #56A2FF）。
- 文档导入：后台新增「文档导入 · 自动识别补充」，工具/美食/知识库模块支持上传 txt / md / csv，自动拆分为可编辑条目；填写 AI 接口地址、Key、模型后可调用 AI 做智能整理。Word/PDF 需要先另存为文本或由后端/OCR 解析。

## 后台编辑

1. 打开页面后点击右上角「后台编辑」，或直接在链接后加 `#admin`。
2. 默认密码：`admin123`（可在「后台设置」模块中修改）。
3. 编辑任意模块 → 点击底部「💾 保存全部」→ 切回首页即可看到生效。
4. 建议：编辑完成后点「导出 JSON」备份；换浏览器时用「导入 JSON」恢复内容。

说明：静态页面没有服务器数据库，编辑内容保存在当前浏览器 localStorage 中。正式部署后，请先用你自己的浏览器完成内容配置，再把公开链接分享给新人。

## 生成公开链接（二选一）

### 方式 A：Vercel（推荐，最快）

1. 访问 https://vercel.com 并登录。
2. 点击「Add New → Project」，上传或导入 `onboarding` 文件夹。
3. 保持默认配置部署，得到 `https://xxx.vercel.app` 公开链接。

### 方式 B：GitHub Pages

1. 把 `宇宙猫ip` 推送到 GitHub 仓库。
2. Settings → Pages → Source 选择 `onboarding` 文件夹。
3. 获得 `https://<用户名>.github.io/<仓库名>/onboarding/` 链接。

## 放入飞书

- 智能工作台：飞书管理后台 → 工作台 → 应用管理 → 网页应用，粘贴公开链接并发布。
- 自动推送：飞书多维表格建「新人信息表」，Base 自动化设置「入职日期 = 今天」→ 发送消息，内容带上公开链接和欢迎语。

## 维护提示

- 所有内容都在 `index.html` 顶部的 `DEFAULT` 数据对象中，紧急情况下可直接改文件。
- 猫猫图片已内嵌在 HTML 中，单个文件即可完整展示，不依赖 `assets/` 目录。
- 页面无外部脚本依赖，分享后不会因网络波动出现空白或报错。
